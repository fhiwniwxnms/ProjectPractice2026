Старт практики: знакомство с заданием и распределение ролей

Провели организационную встречу, разобрали задание на учебную практику и договорились работать в паре. Зарегистрировались на GitVerse, приняли приглашение в репозиторий. Распределили задачи: Анастасия отвечает за документацию и наполнение страниц сайта, Ангелина — за структуру репозитория и скелет сайта. Параллельно посетили Карьерный марафон Московского Политеха, где познакомились со стендами компаний-партнёров и узнали об актуальных требованиях к junior-специалистам.

Настройка Git и первые коммиты

Установили Git, настроили имя пользователя и email через git config, сгенерировали SSH-ключи и привязали к аккаунтам GitVerse. Освоили базовые команды: git clone, git add, git commit, git push, git branch. Ангелина заполнила корневой README.md, Анастасия проверила и дополнила его. Первые коммиты успешно отправлены на GitVerse.
