## Полученные знания

Курс «LLM для всех и каждого» представляет собой практическое введение в мир больших языковых моделей. Материал подаётся без лишней воды - каждый раздел чётко сфокусирован на конкретной теме.

### Что такое LLM и как они работают

Курс объяснил, что большие языковые модели (LLM) - это нейросети, обученные на огромных объёмах текста. Они предсказывают следующий токен на основе контекста, что и позволяет им генерировать связные тексты, отвечать на вопросы и решать разнообразные задачи. Были рассмотрены базовые принципы архитектуры Transformer, лежащей в основе современных LLM: механизм внимания (attention), токенизация, обучение на основе предсказания следующего слова.

### Промпт-инжиниринг

Значительная часть курса была посвящена составлению эффективных запросов. Ключевые принципы:

- **Чёткость и конкретность** - чем точнее сформулирован запрос, тем релевантнее ответ
- **Указание роли и контекста** - модель работает лучше, если объяснить кто ты и зачем нужен результат
- **Разбивка сложных задач** - большие задачи лучше решать по шагам, а не одним запросом
- **Итеративное уточнение** - первый ответ редко финальный, диалог улучшает результат

Курс рассматривал промпты для разных сценариев: написание и редактирование текстов, решение бытовых и рабочих задач, генерация изображений через текстовые описания.

### Этические аспекты

Курс затронул вопросы ответственного использования ИИ: важность проверки фактов (модели могут ошибаться и «галлюцинировать»), авторские права при использовании сгенерированного контента, прозрачность - когда стоит сообщать, что текст написан с помощью ИИ.

## Примеры использования LLM при выполнении практики

В ходе проектной практики я активно использовала Claude (Anthropic) для решения следующих задач:

**Составление структуры сайта** - с помощью ИИ определила какие страницы нужны, что должно быть на каждой из них и в каком порядке расположить разделы.

**Написание документации** - Claude помог составить файл `docs/project.md`: описание проекта, цели, задачи и актуальность были сформулированы на основе материалов презентации по «Проектной деятельности».

**Форматирование контента** - список из 31 участника проекта с ролями был отформатирован в корректную HTML-разметку с карточками.

**Работа с GitVerse** - задавала вопросы по настройке репозитория, SSH-ключей, созданию Issues и правилам коммитов.

Опыт использования LLM в практике показал: ИИ наиболее полезен не как замена работы, а как инструмент для ускорения рутинных задач и быстрого получения объяснений по незнакомым темам.
