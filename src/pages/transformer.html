Архитектура Transformer

Transformer - архитектура нейросети, предложенная в 2017 году в статье «Attention Is All You Need». Она лежит в основе всех современных LLM. Главное нововведение - механизм внимания (attention), который позволяет модели учитывать связи между любыми словами в тексте, независимо от расстояния между ними.

Ключевые компоненты

  • Токенизация - текст разбивается на токены (слова или части слов)
  • Эмбеддинги - каждый токен превращается в числовой вектор
  • Self-Attention - механизм который определяет насколько каждый токен связан с остальными
  • Feed-Forward слои - обрабатывают каждый токен независимо
  • Softmax - на выходе даёт вероятности для следующего токена

Как работает Attention

Представь что ты читаешь предложение «Кошка села на коврик, потому что она устала». Чтобы понять кто такая «она» - нужно связать это слово с «кошкой» в начале предложения. Механизм attention делает именно это: для каждого токена вычисляет веса важности всех остальных токенов и использует их при предсказании.

🔢 Параметры

GPT-4 имеет около триллиона параметров - числовых весов, которые настраиваются в процессе обучения.

📐 Контекстное окно

Максимальный размер текста который модель может обработать за один раз - от 4K до 200K токенов у разных моделей.

🏗️ Энкодер и декодер

Оригинальный Transformer имел обе части. GPT использует только декодер, BERT - только энкодер.

⚙️ Обучение

Модель учится предсказывать следующий токен, минимизируя ошибку на миллиардах примеров.
