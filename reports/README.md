# Отчёты

В этой папке хранятся итоговые отчёты по проектной (учебной) практике в бинарных форматах.

## Файлы

| Файл | Формат | Описание |
|------|--------|----------|
| [practice_report.docx](practice_report.docx) | DOCX | Итоговый отчёт — Цупрун Ангелина Денисовна |
| [practice_report.pdf](practice_report.pdf) | PDF | Итоговый отчёт — Цупрун Ангелина Денисовна |
| [practice_report_template.docx](practice_report_template.docx) | DOCX | Шаблон отчёта по проектной практике |

## Структура отчёта

Отчёт составлен по шаблону [`practice_report_template.docx`](practice_report_template.docx) и включает:

- Введение — общая информация о практике и составе команды
- Раздел 1 — описание проекта «Менеджер задач для ЛК Московского Политеха»
- Раздел 2 — характеристика организации-партнёра (Московский Политех)
- Раздел 3 — описание задания: обязательная часть и часть по выбору (HTTP-сервер на Node.js)
- Раздел 4 — достигнутые результаты по каждому этапу практики
- Заключение и список использованной литературы
